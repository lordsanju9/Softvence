# Scope & Deliverables — Lean Prototype

**Version:** 1.0  |  **Date:** September 2026
**Classification:** Confidential — For Qualified Development Partners

## Phase 1 — Discovery & Architecture
**5 weeks**

Deliverables:
- Finalized prototype backlog.
- Architecture diagram.
- Security model.
- Technology decisions.
- Final API/integration plan.
- Wireframe refinement.

## Phase 2 — Foundation & Wallet
**4 weeks**

Deliverables:
- Web application shell.
- MetaMask connection.
- Network detection.
- Blockchain service.
- Basic portfolio dashboard.

## Phase 3 — AI & Transaction Intelligence
**4 weeks**

Deliverables:
- AI orchestration.
- Read-only tools.
- Transaction history.
- Transaction decoder.
- AI explanations.
- Basic conversation experience.

## Phase 4 — Safe Action Prototype
**3 weeks**

Deliverables:
- Structured swap intent.
- Quote/transaction integration.
- Policy engine.
- Simulation.
- Review screen.
- User wallet signing flow.

## Phase 5 — QA, Deployment & Handover
**4 weeks**

Deliverables:
- Regression testing.
- Security-focused testing.
- CI/CD.
- Staging deployment.
- Documentation.
- Source-code handover.
- Demo and knowledge-transfer session.
- Basic admin configuration (P1, if budget permits).

**Target total:** approximately 20 weeks.


## Phase 6 — Mobile Application Delivery
**Included across implementation phases**

Deliverables:
- Cross-platform iOS and Android prototype.
- Mobile wallet connection flow.
- Mobile AI assistant interface.
- Mobile transaction review and status screens.
- Notification capability for transaction lifecycle events.
