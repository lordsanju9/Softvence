# RFP & Project Governance — Lean Prototype

**Version:** 1.0  |  **Date:** September 2026
**Classification:** Confidential — For Qualified Development Partners

## RFP Objective

Select a partner capable of delivering a secure, focused AI/Web3 prototype within a **USD 200,000 fixed-price ceiling** and approximately **20 weeks**.

## Ideal Partner
- EVM/Web3 experience.
- Wallet integration experience.
- AI/LLM tool-calling experience.
- Strong application security practices.
- Demonstrated ability to deliver lean, security-sensitive prototypes within a fixed budget.

## Responsibilities

### Client
- Product vision and priorities.
- Business decisions.
- Acceptance decisions.
- Required third-party accounts.
- Commercial/legal coordination.

### Vendor
- Technical design.
- Engineering.
- QA.
- Security implementation.
- Deployment.
- Documentation and knowledge transfer.

## Governance

- Weekly status report.
- Weekly demo.
- Shared risk/issue log.
- Written change requests.
- Architecture decisions documented.

## Suggested Evaluation

| Category | Weight |
|---|---:|
| Web3/blockchain expertise | 20% |
| Security capability | 20% |
| Technical architecture | 15% |
| AI capability | 15% |
| Relevant prototype experience | 10% |
| Team quality | 10% |
| Commercial value | 10% |
| **Total** | **100%** |

## IP & Source Code

Client should have continuous repository access. Project-specific source code and documentation should be assigned/licensed to Client under the final contract. Vendor pre-existing IP and third-party components must be identified.

## Vendor Demonstration

Shortlisted vendors should demonstrate, using a test wallet: connect → read balance → explain a transaction → create a structured action → validate it → simulate where supported → require explicit user approval before signing.

## Contract Principle

The vendor may recommend architecture changes, but may not unilaterally expand custody, transaction authority, production scope, or security exceptions.
